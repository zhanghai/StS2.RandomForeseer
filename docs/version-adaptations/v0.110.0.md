# StS2 v0.110.0 adaptation summary

对比范围：游戏源码从 v0.109.1 `27f136e` 到 v0.110.0 `676c46f`。

## 已适配内容

- `CombatManager` 将当前战斗状态及回合生命周期字段集中到新的 `CombatTurnState`。回合结束预测和
  冰冻之眼牌堆归属查询现通过 `_turnState?.State` 读取当前战斗，保留原有的战斗结束后返回空值语义；
  新增的 `CombatId` 用于隔离跨战斗恢复的异步原版任务，不要求 detached prediction state 重构。
- Abundance（富足）现在升级自身时只降低费用，而三个随机能力牌候选无论富足是否升级都会升级。
  对应 `OnPlay` mirror 已改为始终升级候选，仍使用克隆的 `CombatCardGeneration` RNG。
- `AfterCardGeneratedForCombat` 的签名、listener 集合和 dispatch 顺序未变化，但 listener 行为已同步：
  Regalite（君王矿石）改为每回合第一次生成牌时获得格挡，并从 live `_usedThisTurn` 初始化预测态；
  `PillarOfCreationPower`（创世之柱）改为每张生成牌都获得格挡；Rocket Punch（火箭飞拳）改为每次
  触发将费用降低 1 直到打出，而不是直接设为 0。
- 原版 `CardPileCmd.Shuffle` 改为通过批量 `Add` 重建抽牌堆，但仍以相同的 Shuffle RNG 和
  `StableShuffle` 顺序合并弃牌堆与抽牌堆；现有 shadow pile shuffle 无需改变。
- `CardRarityOdds.RollWithBaseOdds` 修正了罕见度累计阈值；Scare 被 Sidestep 替换，Echoing Slash
  稀有度变化，Outbreak 改为稀有技能，Eidolon 不再允许战斗中生成。这些变化会改变同 seed 下的
  奖励及随机印牌候选映射，但不增加 RNG 消耗；预测直接调用原版 rarity roll 并从 canonical 卡池
  经 `CardFactory.FilterForCombat` 取候选，因此自动继承新结果。
- 已排除 generated subtype/serializer、输入设置和 VFX 大改、无关多人 lobby/错误处理以及纯数值
  平衡噪声。RNG 算法、序列化状态、stream 划分、Hook facade 签名与已 mirror 的阶段顺序均未变化。
