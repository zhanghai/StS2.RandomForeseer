# StS2 v0.111.0 adaptation summary

对比范围：游戏源码从 v0.110.1 `a421e19` 到 v0.111.0 `7612a86`。

## 已适配内容

- `CacophonyPower`（不谐合曲）现在在随机选择目标后、造成伤害前先把抽牌计数重置为 33。
  `AfterCardDrawn` mirror 已同步这一顺序，使伤害 hook 引发的嵌套抽牌计入下一次触发，而不会再次立即
  触发不谐合曲；目标仍使用克隆的 `CombatTargets` RNG。
- `BeautifulBracelet`（华美手镯）的拾取效果从玩家选择卡牌改为随机为最多 4 张可附魔牌赋予迅捷 2。
  先古遗物拾取提示现复现原版 `TakeRandom` 对完整候选列表执行的 `UnstableShuffle`，使用克隆的
  `Niche` RNG 展示附魔后的卡牌；串联遗物拾取预测也会推进相同 RNG，避免后续结果偏移。
- v0.111.0 将有手牌回合结束效果的卡牌移入打出堆、结算效果及移入弃牌堆/消耗堆的职责从
  `CardModel.OnTurnEndInHandWrapper` 拆到 `CombatManager.DoTurnEndCards`。效果仍按原手牌顺序串行，只有
  展示动画交错执行；现有 shadow pile 流程已符合新语义，无需重构，仅同步了代码注释和 mirror 文档。
- `CardCmd.Exhaust` 新增结果返回值，`CardPileCmd.GetTweenForCardsChangingPiles` 公开并增加 silent-add
  回调补偿参数，卡牌/药水历史写入增加 `CombatId` 存活检查。这些变化用于原版 UI 或隔离跨战斗异步
  任务，不改变 detached simulator 的耗尽、历史或牌堆语义。
- 已核对所有发生变化且与 exact mirror 相交的卡牌、能力、遗物和怪物。数值/稀有度/关键词变化由
  当前 canonical model 与 dynamic var 自动继承；`CardOnPlayInferrer` 会从 v0.111.0 原始 IL 自动继承
  Expect a Fight、Guiding Star、Hyperbeam 等卡牌的直接攻击、格挡和抽牌模板变化。
- RNG 算法、序列化状态和 stream 划分未变化；Hook facade 签名及 card play、伤害、生命损失、格挡、
  死亡的 listener pass 顺序未变化。Harmony 目标签名保持兼容，所有变牌异步 transpiler 目标源码未变。
  已排除 generated subtype/serializer、动画/VFX、输入、多人握手与错误报告以及纯平衡数值噪声。
